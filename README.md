# 中医院呼吸科随访APP

#### 介绍

软件针对于呼吸科医生随访需要进行开发，医师能够使用该软件对肺结节、肺癌随访信息进行记录和完善，同时嵌入了部分数据可视化内容，同时构建了一个过滤检索系统，能够方便进行科研工作。

主要功能：

- 患者随访信息数字化管理
- 肺结节/肺癌病程动态追踪
- 检查报告结构化录入
- 多维度数据可视化分析
- 科研数据筛选导出功能
- 随访提醒与消息通知

#### 软件架构

技术栈说明：

- 前端：Vue、Element框架
- 后端：Spring Boot + MySQL
- 数据分析：Python+Pandas+Matplotlib
- 安全架构：JWT认证 + 数据加密传输

模块组成：

1. 患者管理模块
2. 随访记录模块
3. 影像资料模块
4. 数据分析看板
5. 科研检索模块
6. 系统管理模块

#### 安装教程

Android版本安装：

1. 下载最新APK安装包
2. 在手机设置中允许"安装未知来源应用"
3. 点击APK文件进行安装
4. 首次打开需授予存储权限

iOS版本安装：

1. 通过TestFlight获取测试版本
2. 使用医院分配的Apple ID登录安装
3. 在设置-通用-设备管理中信任开发者证书

前端运行命令：

- Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
- npm install
- npm install --save-dev electron
- npm install electron-builder --save-devnpm run build
- npm run dist
- npm run dev

开发者环境搭建：

1. 克隆代码仓库
2. 前端配置：安装Vue环境
3. 后端配置：安装JDK21+MySQL8.0
4. 导入初始化SQL脚本

#### 使用说明

医生端使用：

1. 登录：使用医院统一账号密码登录
2. 患者管理：点击"+"添加新随访患者
3. 随访记录：选择模板快速录入随访信息
4. 数据分析：查看患者历史数据趋势图
5. 科研检索：设置筛选条件导出CSV数据

注意事项：

- 每日23:00-1:00为系统维护时段
- 敏感数据需通过院内VPN访问
- 患者隐私数据禁止截图外传

#### 详细分工

1. 郭禹轩：
   - 肺结节是肺部小异常团块，可能预示肺癌。由于症状不明显，许多高危人群易忽视定期检查，增加恶化风险。该模块提醒医生对近期（7 天内）需要复查的患者进行跟进，确保不遗漏高危人群，降低恶化风险；
   - 基于权限区分，提供医生端与管理员端的综合信息管理与账户审核功能，维持系统安全与可控；
   - 将系统内已录入的患者信息、随访报告信息等按医院纸质病例模板生成标准PDF电子文档，用于打印归档、病历传送与远程复诊资料预览。
2. 高梓健：
   - 针对肺结节患者，支持类型匹配、单次随访报告录入、多结节动态表单、影像存储与展示、复查信息和标签管理，为医生提供完整的随访闭环。
   - 当肺结节恶化为肺癌时，支持自动和手动标记，并对诊疗方式与疗效进行持续跟踪，贯穿诊断到疗效评估全过程。
   - 核心科研实践模块，基于历史随访信息帮助医生进行病情研究及药物验证科研实践，帮助医生进行药物效果验证，以及通过历史随访信息帮助医生对者病情进行分析，避免发展为肺癌。提供时间、标签、关键词等多维度、强交互的快速检索与预览。
3. 李梦真：
   - 系统平台架构模块：搭建一套基于 Vue + Electron 的多端统一基础框架，前后端分离，后端基于 Spring Boot，支撑网页端与桌面端统一 UI、统一接口，并为后续功能留足扩展能力。
   - 用户登录与权限管理模块：实现账号密码登录、动态隐藏/显示密码、医生与管理员两类角色鉴权，并提供新医生注册申请流程及各类异常状态的友好提示，确保系统安全与良好体验。
   - 患者基本信息管理模块：管理患者基本信息，从新建立卡、信息展示到修改与删除，构建“患者信息卡”，串联后续所有随访与病情功能，是系统核心数据入口。
