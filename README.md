# 中医院呼吸科随访APP

#### 介绍

软件针对于呼吸科医生随访需要进行开发，医师能够使用该软件对肺结节、肺癌随访信息进行记录和完善，同时嵌入了部分数据可视化内容，同时构建了一个过滤检索系统，能够方便进行科研工作。

主要功能：

- 患者随访信息数字化管理
- 肺结节/肺癌病程动态追踪
- 检查报告结构化录入
- 多维度数据可视化分析
- 科研数据筛选导出功能
- 随访提醒与消息通知

#### 软件架构

技术栈说明：

- 前端：Vue、Element框架
- 后端：Spring Boot + MySQL
- 数据分析：Python+Pandas+Matplotlib
- 安全架构：JWT认证 + 数据加密传输

模块组成：

1. 患者管理模块
2. 随访记录模块
3. 影像资料模块
4. 数据分析看板
5. 科研检索模块
6. 系统管理模块

#### 安装教程

Android版本安装：

1. 下载最新APK安装包
2. 在手机设置中允许"安装未知来源应用"
3. 点击APK文件进行安装
4. 首次打开需授予存储权限

iOS版本安装：

1. 通过TestFlight获取测试版本
2. 使用医院分配的Apple ID登录安装
3. 在设置-通用-设备管理中信任开发者证书

前端运行命令：

- Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
- npm install
- npm install --save-dev electron
- npm install electron-builder --save-devnpm run build
- npm run dist
- npm run dev

开发者环境搭建：

1. 克隆代码仓库
2. 前端配置：安装Vue环境
3. 后端配置：安装JDK21+MySQL8.0
4. 导入初始化SQL脚本

#### 使用说明

医生端使用：

1. 登录：使用医院统一账号密码登录
2. 患者管理：点击"+"添加新随访患者
3. 随访记录：选择模板快速录入随访信息
4. 数据分析：查看患者历史数据趋势图
5. 科研检索：设置筛选条件导出CSV数据

注意事项：

- 每日23:00-1:00为系统维护时段
- 敏感数据需通过院内VPN访问
- 患者隐私数据禁止截图外传
